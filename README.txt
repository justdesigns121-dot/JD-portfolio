PREVIEW
Open index.html in Chrome, Edge, Firefox or Safari.

FREE HOSTING (GITHUB PAGES)
1. Create/sign in to a GitHub account.
2. Create a public repository named jatin-dhumak-portfolio.
3. Upload all four files while preserving their names and folder structure.
4. Open repository Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select the main branch and /(root), then Save.
7. GitHub will provide a public URL after deployment.
